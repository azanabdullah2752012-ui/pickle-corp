CRAFT STANDARDS

The Atelier
Design Manifesto.

I.

Every pixel is intentional

We never ship a component without knowing exactly why it looks the way it does. No default shadows, no arbitrary spacing, no copy-pasted templates.

II.

Performance is craft

60fps is a minimum, not a target. We profile every render loop, avoid layout thrash, and cache every DOM read outside animation frames.

III.

Accessibility is non-negotiable

Every focus ring, every ARIA label, every contrast ratio is verified with real tools — not eyeballed. Users deserve a good experience regardless of ability.

IV.

Build only what you need

If a vanilla JS function covers it, we don't reach for a library. If a CSS custom property does it, we don't add a build step. Simplicity is the final sophistication.
